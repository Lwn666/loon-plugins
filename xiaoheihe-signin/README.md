# 小黑盒自动签到 + 每日任务 - Loon 插件

小黑盒（xiaoheihe）每日自动签到 + 每日任务，获取 H 币 + 经验。基于社区共享 hkey 签名服务实现 iOS 新版签名。

## 功能

- ✅ 每日自动签到（默认 08:00，可自定义）
- ✅ 签到状态查询（防重复签到）
- ✅ **每日任务自动完成**（可选开关）：
  - 分享任意帖子到社交平台（EXP+10 / H币+100 / 盒电+1）
  - 分享游戏详情到社交平台（EXP+10）
  - 分享游戏评价到社交平台（EXP+10）
- ✅ 任务进度统计
- ✅ 多账号支持
- ✅ 结果通知（成功/失败/登录态失效）

## 通知内容

签到完成后推送账号总览：

```
✅ 签到 · 成功 +30H币 连签19天
💰 H币 6727 | ⚡盒电 226 | Lv.10 | 240/2400 | 连签19天 · 升级约36天
📋 任务状态:
  ✅ 签到
  ✅ 分享任意帖子到社交平台
  ✅ 分享游戏详情到社交平台
  ✅ 分享游戏评价到社交平台
  ⏳ 前往获取今日灵感选题
✅ 分享帖子 · 完成
📊 任务进度 · 4/5
```

- **H币 / 盒电 / 等级 / 经验进度**：实时余额
- **连签天数**：`sign_in_streak`，连续签到不中断
- **升级约 X 天**：按每日实际经验估算 = 签到经验 + 每日任务经验（30），已包含连签翻倍规则

> 💡 **连签翻倍**：连续签到 7 天以上，签到奖励的经验和 H 币翻倍（30 → 60），升级速度自动减半。

## 安装

1. 导入插件：Loon → 插件 → 添加 → 选择 `xiaoheihe-signin.plugin`
2. 配置参数：
   - **Cookie**（必填）：从小黑盒 App 抓包获取，格式 `heybox_id#pkey=xxx;x_xhh_tokenid=xxx`
   - **签到时间**：cron 表达式，默认 `0 8 * * *`（每天 08:00）
   - **每日任务**：开关，开启后自动完成分享类任务（建议开启）
3. 开启插件即可

## 获取 Cookie（重要）

1. 开启 Loon 抓包（需配置证书）
2. 打开小黑盒 App，进入「我的」页面（或手动签到一次）
3. 在抓包记录中找 `api.xiaoheihe.cn` 的请求
4. 复制请求头中的：
   - **Cookie** 里的 `pkey=xxx;x_xhh_tokenid=xxx`
   - URL 参数里的 `heybox_id=88854293`
5. 填进插件参数：`88854293#pkey=xxx;x_xhh_tokenid=xxx`

> ⚠️ Cookie 有效期很长（数月），但**换设备/重装 App 会失效**。失效后重新抓包更新即可。

## 多账号

用 `&` 分隔多个账号：

```
88854293#pkey=a;x_xhh_tokenid=b&98765432#pkey=c;x_xhh_tokenid=d
```

## 环境变量（可选）

| 变量 | 说明 | 默认值 |
|---|---|---|
| `XHH_HKEY_SERVER` | 自定义 hkey 签名服务 | `https://hkey.qcciii.com/hkey` |
| `XHH_IMEI` | 设备 imei（需与 hkey 服务匹配） | `4187fb55b1be198a` |
| `XHH_ENABLE_TASKS` | 启用每日任务（`1`=启用） | 关闭 |
| `BLACKBOX_COOKIE` | 替代插件参数的 Cookie | 无 |

## 每日任务说明

每日任务通过**加密事件上报**（mode=report → data.xiaoheihe.cn）完成分享类任务，实测验证全部可完成：

- **分享帖子**：拉取帖子流 → view_time 上报 → 分享点击 → tap/success 事件
- **分享游戏详情**：拉取游戏推荐 → tap/success 事件（src=game_detail）
- **分享游戏评价**：拉取游戏评论 → tap/success 事件（src=game_comment）

> ⚠️ 任务需要 30~60s 完成（含等待结算），插件 timeout 已设为 180s。
> ⚠️ 个别账号任务标题可能不同，脚本按标题匹配，未匹配到会自动跳过。

## 原理说明

小黑盒 iOS 版接口签名（`hkey`）由 `libhbsecurity.so` 生成（hmac-sha1 + 设备指纹），**无法在 Loon 沙箱内纯 JS 复现**。

本插件采用社区共享方案：
1. 调用 `hkey.qcciii.com/hkey` 签名服务，传入 `path + time + imei + heybox_id` 获取实时 `hkey` + `version/build`
2. 用返回的签名构造合法请求，调用签到接口

⚠️ **依赖第三方服务**：签名服务为社区共享（非本项目维护），若失效需更换 `XHH_HKEY_SERVER`。

## 接口清单

| 接口 | 用途 |
|---|---|
| `/task/sign_v3/sign` | 执行签到（幂等，重复返回 `state:ignore`）|
| `/task/sign_v3/get_sign_state` | 查询签到状态（含连签天数、当日经验/H币）|
| `/task/list_v2/` | 任务列表 + 用户信息（H币/盒电/等级/经验）|
