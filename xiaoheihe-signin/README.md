# 小黑盒自动签到 + 每日任务 - Loon 插件

小黑盒（xiaoheihe）每日自动签到 + 每日任务，获取 H 币 + 经验 + 盒电。基于社区共享 hkey 签名服务实现 iOS 新版签名。

## 功能

- ✅ 每日自动签到（默认 08:00，可自定义）
- ✅ **Cookie 自动捕获**：打开小黑盒 App 任意页面自动更新，无需手工抓包
- ✅ 签到状态查询（防重复签到）
- ✅ **每日任务自动完成**（可选开关）：
  - 分享任意帖子到社交平台（EXP+10 / H币+100 / 盒电+1）
  - 分享游戏详情到社交平台（EXP+10）
  - 分享游戏评价到社交平台（EXP+10）
- ✅ 任务进度统计
- ✅ 多账号支持
- ✅ 结果通知（成功/失败/登录态失效）

## 通知内容

签到完成后推送账号总览：

```
📅 ✅ 签到 · 成功 +60H币 +60经验 连签19天
🔥 连续签到: 19天
📈 今日获得: +150经验 / +220H币 / +2盒电
✅ 分享帖子 · 完成
✅ 分享游戏详情 · 完成
✅ 分享游戏评价 · 完成
📊 任务进度: 4/5
💰 H币: 6727 | ⚡盒电: 226 | Lv.10 | 经验 240/2400
⏳ 预计升级: 约14天（按每日 +150经验）
```

- **H币 / 盒电 / 等级 / 经验进度**：实时余额（取自 `list_v2` 的 `user.level_info` / `user.battery`）
- **连签天数**：从 `/task/sign_list/` 尾部连续 `is_sign=true` 统计（含补签，与 App 一致）
- **今日获得**：以「执行前 → 执行后」用户信息差值为准（接口真实值），差值不可用时退回按 `award_desc_v2` 累加
- **任务进度**：只统计「每日任务」分组（脚本实际操作的那组），不含「灵感推荐」等无法自动完成的分组
- **升级约 X 天**：按今日实际所得推算

> 💡 **连签翻倍**：连续签到 7 天以上，签到奖励的经验和 H 币翻倍（30 → 60）。
>
> ⚠️ 早期版本曾用 `result.level_info` 统计签到奖励——那是**脏数据**（coin=0 / exp=5870 / max_exp=20），真实值在 `sign_in_exp` / `sign_in_coin`。

## 安装

1. 导入插件：Loon → 插件 → 添加 → `xiaoheihe-signin.plugin`
2. 配置参数：
   - **自动捕获Cookie**（推荐开启）：打开小黑盒 App 任意页面即自动获取，无需手填
   - **手动Cookie**（可选）：自动捕获失效时的兜底
   - **签到时间**：cron 表达式，默认 `0 8 * * *`（每天 08:00）
   - **每日任务**：开关，开启后自动完成分享类任务（建议开启）
   - **调试模式**：输出详细日志
3. 开启插件，打开一次小黑盒 App 完成凭证捕获即可

## 手动获取 Cookie（兜底方案）

自动捕获失效时才需要：

1. 开启 Loon 抓包（需配置证书）
2. 打开小黑盒 App，进入「我的」页面（或手动签到一次）
3. 在抓包记录中找 `api.xiaoheihe.cn` 的请求
4. 复制请求头 Cookie 里的 `pkey=xxx;x_xhh_tokenid=xxx`，以及 URL 参数里的 `heybox_id=88854293`
5. 填进「手动Cookie」参数：`88854293#pkey=xxx;x_xhh_tokenid=xxx`

> ⚠️ Cookie 有效期很长（数月），但**换设备/重装 App 会失效**。失效后重新抓包更新即可。

## 多账号

用 `&` 或换行分隔多个账号：

```
88854293#pkey=a;x_xhh_tokenid=b&98765432#pkey=c;x_xhh_tokenid=d
```

## 环境变量（可选）

| 变量 | 说明 | 默认值 |
|---|---|---|
| `XHH_IMEI` | 设备 imei（需与 hkey 服务匹配） | `4187fb55b1be198a` |
| `XHH_BUDGET_MS` | 单账号时间预算（ms），多账号时防超时 | `70000` |
| `BLACKBOX_COOKIE` | 替代插件参数的 Cookie | 无 |

## 每日任务说明

每日任务通过**加密事件上报**（mode=report → data.xiaoheihe.cn）完成分享类任务：

- **分享帖子**（`task_id=1`）：拉取帖子流 → view_time 上报 → 分享点击 → tap/success 事件
- **分享游戏详情**（`task_id=19`）：拉取游戏推荐 → tap/success 事件（src=game_detail）
- **分享游戏评价**（`task_id=31`）：拉取游戏评论 → tap/success 事件（src=game_comment）

任务状态按 `report_extra.task_id` 匹配，**不依赖中文标题**——服务端改文案不会导致任务被跳过。

> ⚠️ 任务需要 30~60s 完成（含等待结算），插件 timeout 已设为 180s。
> ⚠️ 单账号时间预算默认 70s，超出会跳过剩余任务（次日补跑），避免多账号时整个脚本被 Loon 强杀导致通知都发不出。
> ⚠️ 个别账号任务标题可能不同，脚本按标题匹配，未匹配到会自动跳过。

## 原理说明

小黑盒 iOS 版接口签名（`hkey`）由 `libhbsecurity.so` 生成（hmac-sha1 + 设备指纹），**无法在 Loon 沙箱内纯 JS 复现**。

本插件采用社区共享方案：
1. 调用 `hkey.qcciii.com/hkey` 签名服务，传入 `path + time + imei + heybox_id` 获取实时 `hkey` + `version/build`
2. 用返回的签名构造合法请求，调用签到接口

⚠️ **依赖第三方服务**：签名服务为社区共享（非本项目维护）。若失效会推送「签名服务不可用」通知（不会静默失败）。
⚠️ 签名绑定 `_time`，请求必须用与换签时相同的秒级时间戳，否则服务端返回「非法请求」。

## 接口清单

| 接口 | 用途 |
|---|---|
| `/task/sign_v3/sign` | 执行签到（幂等，重复返回 `state:ignore`）|
| `/task/sign_v3/get_sign_state` | 查询签到状态（`sign_in_exp` / `sign_in_coin` / `sign_in_streak`）|
| `/task/sign_list/` | 签到日历（算连签天数）|
| `/task/list_v2/` | 任务列表 + 用户信息（H币/盒电/等级/经验）|

`list_v2` 的 `task_list[].tasks[]` 关键字段：`title` / `type` / `state`（`finish`|`waiting`）/ `report_extra.task_id` / `award_desc_v2[]`。奖励币种靠 `award_desc_v2[].icon` 文件名区分（经验 `b9aca51c…` / H币 `c10d89ae…` / 盒电 `e63b192a…`），`desc` 为 `+数字` 才是奖励。
