# 药房网自动签到 (yfw-signin)

m.yaofangwang.com 每日自动签到。打开签到页自动捕获 ASP.NET_SessionId，定时签到并推送结果。

## 安装

1. Loon → 插件 → 添加 → `yfw-signin.plugin`
2. 开启「凭证自动捕获」开关
3. 用药房网 App/H5 打开签到页（触发一次凭证捕获）
4. 每天 08:00 自动签到（可在插件参数改时间）

## 2026-08-27 修复

- **文案修正**：`signalltime` 实际是「连续签到天数」（每周一重置），原脚本误标为「累计签到」→ 已改为「连续签到 X 天，本周第 X 天」
- **补 accountid**：页面真实签到请求带 `accountid`，原脚本未带 → 现在自动从签到页提取 accountid 再签到，数据更准确
